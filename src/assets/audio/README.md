# Audio provenance

Version 0.1's first audio identity is generated at runtime by the project's
Web Audio implementation in `src/core/AudioManager.ts`.

- All motifs, oscillator patches, envelopes, timing, and mixing code were
  created specifically for Castle of the Last Warden.
- No sampled, ripped, or third-party music and sound effects are included.
- The title, sanctuary, forest, and defense scores are lightweight original
  procedural motifs. Combat, bell, forge, progression, and defense sounds are
  original synthesized effects.
- Audio is cosmetic and failure-safe: unavailable or suspended browser audio
  never blocks gameplay.

Future recorded performances or samples must list their creator, source URL,
license, and any required attribution in this file before inclusion.
